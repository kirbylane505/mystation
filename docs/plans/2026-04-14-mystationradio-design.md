# MyStationRadio — Design Doc

**Date:** 2026-04-14
**Author:** CHANDLA (approved by Mike Page)
**Status:** APPROVED — ready for implementation plan

---

## 1. Goal

Launch `/mystationradio` — a non-stop, radio-style listening tab on MyStation. User searches an artist, presses "Play Station," and music plays all day (smart-mix 80% selected artist / 20% other MyStation creators) until the user stops or switches station. Shared links to this tab auto-start playback on that tab only, without triggering the normal global shared-link auto-play system.

---

## 2. Architecture

- **Route:** `/mystationradio` (Next.js App Router, client-heavy)
- **Audio engine:** existing `AudioPlayer.jsx` module-level `globalAudio` singleton — unchanged
- **State:** existing `playerStore` (Zustand) handles track/play state; new `radioStore` handles station + queue metadata
- **Catalog sources:**
  - Static: `src/data/tracks.js` (200+ Mike Page tracks)
  - Dynamic: Supabase `creators` + `creator_tracks` (every signed-up artist)
- **Tab placement:** Navbar "Radio" link + BottomTabBar 6th "Radio" tab (new, additive)

---

## 3. Data model

### Catalog endpoint
`GET /api/mystationradio/catalog`
- Merges static Mike Page tracks with `creator_tracks` rows
- Returns `{ artists: [{ slug, name, trackCount, avatar }], totalTracks }`
- Cached server-side for 5 minutes

### Search endpoint
`GET /api/mystationradio/search?q=<query>`
- Searches `creators.display_name`, Mike Page static artist field, featured-artist strings in `tracks[].featured`
- Returns top 10 matches with track counts

### Station queue builder
`GET /api/mystationradio/station?artist=<slug>&offset=<n>`
- Returns pre-shuffled queue of 200 tracks
- Weighted 80% from selected artist + 20% random from other creators platform-wide
- If artist has <10 tracks, flips to 60/40 to avoid fast repeats
- Uses seed from request time + offset so each batch is distinct
- Client refills background when queue has <20 tracks remaining

## 5. Shared-link auto-play

**URL:** `https://mystationlive.com/mystationradio?station=<slug>` (or bare = Mike Page default)

**Behavior:**
- On mount, `MyStationRadioClient` reads `?station=` param
- Fetches queue, calls `playerStore.setTrack(queue[0])` + triggers play
- **Global shared-link auto-play system disabled on this route** — gated by `if (pathname === '/mystationradio') return` at the global listener
- Every other route: global shared-link system untouched

**OG tags:**
- `og:title` = `<Station> Radio · 24/7 on MyStation`
- `og:image` = generated by `/api/og/mystationradio` (artist avatar + RADIO badge)
- `og:audio` = **intentionally omitted** (no iMessage duplicate play button)

## 6. State

### New `radioStore.js` (Zustand)
```js
{
  activeStation: null | { slug, name, avatar },
  queue: Track[],
  cursor: 0,
  isRadioActive: boolean,
  history: Track[],

  startStation(slug),
  skip(),
  stop(),
  refillQueue(),
}
```

### Wiring
- `radioStore.startStation()` → fetch queue → `playerStore.setTrack(queue[0])` → play
- `playerStore` onEnded listener → if `isRadioActive` → `cursor++` → load next
- When `cursor >= queue.length - 20` → background-fetch next 200 via `station?offset=`
- Cross-page persistence: station survives route changes because audio singleton lives in `AudioPlayer.jsx`

### STOP
`radioStore.stop()` clears queue + station, sets `isRadioActive=false`, calls `playerStore.stop()`. Distinct from pause.

## 7. Error handling

| Scenario | Behavior |
|---|---|
| Supabase fetch fails | Fall back to Mike Page static catalog only; toast "Using cached catalog" |
| Empty search | "No stations found" state |
| Track audio 404s | Auto-skip to next; log error; don't block |
| Offline during refill | Keep playing current queue; retry every 30s |
| Switch station mid-playback | Swap immediately (Mike specified) |
| Invalid `?station=` slug | Default to Mike Page Radio; toast "Station not found" |
| Artist has <10 tracks | 60/40 smart mix instead of 80/20 |

## 8. Testing

- **Unit:** queue builder 80/20 ratio, pre-shuffled, no repeat within 20-slot window
- **Integration:** search returns expected matches for partial / full / substring queries
- **E2E:** load `/mystationradio?station=mike-page` → auto-play within 3s, advances on end, STOP clears state
- **Manual smoke:** play 30+ min continuous, confirm no gap during queue refill
